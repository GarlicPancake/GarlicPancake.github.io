About Me

I'm a graduate student at George Washington University pursuing an MS in Information Systems Technology. Live DC Metro Arrival Board

A 64x32 LED display that shows the next three train arrivals for a Metro station. A MatrixPortal M4 pulls live data from the WMATA API through a small proxy server. A corner dot shows green for live data and red when cached.

Built with: MatrixPortal M4, CircuitPython, Python, WMATA API
